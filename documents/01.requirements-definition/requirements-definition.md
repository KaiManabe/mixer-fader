# 要件定義

## 1. 概要
- Windowsの音量ミキサを操作する専用ガジェット
- デバイスにアプリケーションの設定音量，レベル，アイコンを表示
- デバイスのロータリーエンコーダで設定音量を操作
- マスターデバイスとスレーブデバイスを製作
  - スレーブデバイスはデイジーチェーン接続で可変長個数を接続

## 2. 機能要件
### 2.1. 表示
- マスターデバイスおよびスレーブデバイスはLCDディスプレイと16個の縦列ledをもつ
  - LCDディスプレイにはアイコンおよび設定音量(数字)を表示する
  - ledはレベルメータとして，マスター/アプリケーションの出力レベルを表示する(緑，黃，赤)

### 2.2. 操作
- マスターデバイスは2つのロータリーエンコーダをもつ
  1. ページ送り用
     - `スレーブ個数 < 起動中アプリケーション個数`な場合に，これを回転することでページ送りをする
  2. 音量操作用
     - これを回転することで，マスターの設定音量を変更する
     - クリックすることで，マスターをミュートする
- スレーブデバイスはそれぞれ1つのロータリーエンコーダをもつ
  - これを回転することで，対象のアプリケーションの設定音量を変更する
  - クリックすることで，ミュートする

### 2.3. 接続
- マスターデバイスはUSB type-C端子をもつ
  - WindowsマシンとUSBケーブルで接続する
- マスターデバイスとスレーブデバイスはマグネットで接続・固定する
  - 1台のマスターを左端に配置
  - 任意の台数のスレーブをマスターの右にデイジーチェーン接続
  - 右端にエンドカバーを接続

## 3. 非機能要件
### 3.1. ドライバ
- Windows10/11で動作
- インストール後はバックグラウンドに常駐
- マスターが接続されたら自動認識
  
### 3.2. ファームウェア
- UARTにログを出力
- UARTを接続するためのロギング用隠し端子を配置
